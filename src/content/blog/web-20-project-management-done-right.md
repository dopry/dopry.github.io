I keep coming across cool applications lately, and [Dev Shop](https://web.archive.org/web/20120707065045/http://www.devshop.com/) is definately a nice one for developers everywhere. On a recent project, I got stuck with arduous task of being the project manager and keeping time lines for about 5 people, while trying to manage myself and my own time. To say the least, I had a hard time estimating how much of my development time the project management tasks would consume, estimating how much time changes to the project requirements would affect the project time line as a whole, and gaugeing everyone's working habits. I started exploring whats available in the current project management web 2.0 world. I found only two real contenders. The ever infamous 'Basecamp', which for all its simplicity doesn't really offer anything more
than some trumped up task tracking a bunch of automated emails. Then I came along Dev Shop.

This is a really awesome application. Generates gantt charts, understands task dependencies, does timeline estimation for you, even accounts for previous behavior of its users. It has all the features that I've really wanted to see in a project management app for the last two years... So if you haven't yet, you should give [Dev Shop](https://web.archive.org/web/20120707065045/http://www.devshop.com/) a spin!
