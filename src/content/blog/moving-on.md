I left NowPublic a few months ago for personal reasons and
a lack of interest in the news.

I've moved on to Eighty Elements, a Vancouver based
interactive media startup that specializes in integrating
Flash, Flex, and Drupal. Blame Craq. I've been getting
boucou time to work on Filefield, Derivative, and
Transformer. Which has led to some supporting modules I've
already released including Mime Detect, ImageAPI and the
soon to be released VideoAPI and FFmpeg modules.

Look for us at DrupalCon. We're going to be hosting a
Media Panel from what I understand. I know I want to cover
topics like hook_file in core, media api interfaces (Eaton
this is one you'll like "See dopry do OO."), and file meta
data handling.

So keep an eye on EightyElements, we promise to have a
real web site up soon. You know us web developers, we can
never get time to work on our own sites.
